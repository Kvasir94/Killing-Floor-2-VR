# Optional Breacher experiment

Breacher is an early optional perk/weapon experiment, disabled by default.
Only a package built with Breacher can offer it. All players in a hosted session
must use matching packages and settings; ordinary Solo/Host/Join does not need it.

If your invited package includes it, enable the launcher's Breacher option to
try the provisional perk and Deadbolt starting weapon/trader entry. It has no
promise of balanced prices, damage, progression or complete in-game acceptance.
Use the normal weapon controls: trigger fires; X/A reloads in Button mode;
physical movement handles melee/bash where supported. Desktop uses stock bindings.

Deadbolt's experimental projectile grows as it hits distinct living enemies.
Report incorrect repeat hits, unexpected obstruction penetration, remote
presentation, perk selection or trader purchase problems. More advanced corpse
pinning and the rest of the proposed arsenal are incomplete.

For a report include build ID, Solo/Host/Join, VR/Desktop, perk, weapon, relevant
options and steps. Use Save logs for a bug report, review the ZIP, and send it to
the destination supplied with your invitation. Disable Breacher for ordinary play.
